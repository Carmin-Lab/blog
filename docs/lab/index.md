# 山甲实验室

我目前担任山甲实验室技术负责人。这个栏目用于整理适合公开的团队技术实践，以及我在协作、工程建设和技术责任上的阶段性理解。

## 我们关注什么

- 把研究想法转化为稳定、可验证的技术原型
- 建立清晰、可复用、可持续维护的工程流程
- 在协作中沉淀工具、规范和共同语言
- 尊重数据安全、研究伦理与知识产权边界

## 这里将会出现

### 技术建设

公开分享技术选型、项目结构、实验管理和质量保障方面的经验。内容以可复用的方法为主，不涉及内部系统细节。

### 团队协作

记录需求澄清、任务拆解、技术评审和跨角色沟通中的方法与反思。

### 阶段日志

在合适的时间整理可以公开的里程碑、工具和复盘。尚未完成或未经团队确认的信息不会提前发布。
