# 内容与平台

不同平台适合不同深度和节奏的表达。这里将作为统一入口，让文章、项目和公开动态彼此连接，同时避免同一内容被简单重复地搬运。

## 内容矩阵

| 平台 | 主要内容 | 当前状态 |
| --- | --- | --- |
| 本博客 | 长篇研究笔记、博士旅程、项目复盘与生活随笔 | 持续更新 |
| GitHub | 开源代码、工具和可复现的技术实践 | [访问 Carmin-Lab](https://github.com/Carmin-Lab) |
| 微信公众号 | 阶段性文章、科普表达与近况分享 | 即将开放 |
| 知乎 | 问题讨论、研究经验与专题文章 | 即将开放 |
| 山甲实验室平台 | 团队项目、技术建设与正式动态 | 即将开放 |
| CardioMind AI 平台 | 项目愿景、产品进展与公开合作信息 | 即将开放 |

## 内容如何互相连接

- 博客保留相对完整、适合长期检索的原文
- 公众号和知乎可发布适合各自读者的改写或摘要
- GitHub 承载能够公开的代码、配置和版本记录
- 平台页面承载项目与团队的正式信息

未来新增入口时，我会在这里补充经过确认的官方链接。任何尚未公开的平台都不会使用临时或未经验证的地址。
