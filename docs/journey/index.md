# 心路历程

这里不是一份按年份排列的履历，而是我对一路走来那些选择、转折和感受的长期记录。

博士研究、团队技术工作和项目发起人的身份时常同时发生。它们带来机会，也带来责任、犹豫和取舍。我希望保留这些不那么容易被成果列表看见的部分：为什么出发，如何在不确定中继续，以及一个人的认识怎样被时间慢慢改变。

## 我会在这里写什么

- **选择与转折**：研究方向、职业角色和个人目标如何逐渐形成
- **困难与恢复**：面对实验停滞、计划变化和长期压力时的真实经验
- **责任与协作**：从独立研究走向团队协作后，对技术负责人的重新理解
- **理想与现实**：如何让医学人工智能的长期愿景落在一件件具体的小事上
- **生活与自我**：研究之外，阅读、关系、城市和日常如何塑造一个人

## 写作约定

我会尽量在事情沉淀之后再写，不把情绪包装成答案，也不把阶段性的进展描述成已经实现的目标。涉及团队、合作方、研究数据或尚未公开的工作时，只保留能够公开讨论的个人经验。
