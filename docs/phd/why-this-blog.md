# 为什么建立这个博客

建立这个博客，并不只是为了整理技术资料。

我更希望它成为一份长期的读博记录：既有研究方向、论文阅读和项目实践，也有选择、困惑、失败、成长，以及研究之外平静而具体的生活。

## 为什么想记录

博士阶段常常以论文、项目和阶段成果来衡量，但真正构成这段经历的，还有大量难以被简历呈现的过程：

- 一个研究问题是怎样慢慢变清楚的
- 实验停滞时如何重新寻找方向
- 怎样在长期目标与日常任务之间保持节奏
- 如何理解合作、责任和技术领导力
- 如何在紧张的研究之外认真生活

这些过程未必都有标准答案，但值得被诚实地记录下来。

## 我希望分享什么

这个博客会围绕四条线展开：

1. **博士旅程**：记录读博期间的思考、方法和阶段变化。
2. **研究成长**：整理医学多模态模型、基础大模型和时空病理方向的学习与公开笔记。
3. **项目实践**：记录 CardioMind AI、山甲实验室以及开源工具中适合公开的经验。
4. **生活随笔**：保存研究之外的阅读、观察、日常和那些让我保持平静的事物。

## 写作原则

我希望这里的内容尽量真实、克制且可以长期回看。

- 不为了显得顺利而省略困难
- 不把早期想法包装成确定结论
- 不公开患者数据、未发布成果和团队内部信息
- 区分事实、引用、个人理解与尚未验证的判断
- 保留研究之外真实的生活感受

如果这些记录恰好也能给正在读博、准备读博或从事医学人工智能研究的人带来一点参考，那会是一件很有意义的事。
