# 合作与联系

欢迎围绕医学人工智能研究、工程实践和长期内容建设进行真诚、具体的交流。为了让沟通更有效，建议在联系时简要说明背景、希望讨论的问题和预期合作方式。

## 期待的合作方向

### 科研与学术交流

- 医学多模态模型与基础大模型
- 数字病理、时空建模与多模态学习
- 医学人工智能评测、可靠性与可解释性
- 公开论文、方法和研究工具的讨论

### 技术与工程协作

- 研究原型与工程系统之间的衔接
- 数据与实验流程、模型评测和工具链建设
- 面向科研团队的开源工具与基础设施

### 项目与平台共建

- 山甲实验室适合公开的技术交流
- CardioMind AI 的研究、工具和生态合作
- 医学人工智能内容、社区与公益性知识建设

### 内容交流

- 博士成长与科研方法主题的访谈或分享
- 公众号、知乎和博客之间的专题共创
- 有明确来源、尊重版权的内容转载与授权

## 暂不接受的事项

- 涉及患者隐私、未经授权的数据或不合规的数据使用
- 要求披露未公开研究、团队内部资料或合作方信息
- 无法说明真实目的的推广、导流或批量转载
- 将研究交流包装为诊断、治疗或个体化医疗建议
