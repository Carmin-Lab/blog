# 关于我

我是庞俊杰，中国科学院大学人工智能学院博士在读，也在承担山甲实验室技术负责人和 CardioMind AI 发起人的工作。

这些身份并不是彼此割裂的标签。研究让我持续追问问题，团队工作让我学习把想法变成可靠的协作，而项目建设让我更认真地思考技术如何走向长期价值。这个博客用来保存它们交汇时真实发生的过程。
