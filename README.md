# Carmin Lab Research Blog

庞俊杰的读博、研究与生活博客，使用 [VitePress](https://vitepress.dev/) 与
[Teek](https://vp.teek.top/) 官方 npm 包从零搭建。

公开地址：<https://carmin-lab.github.io/blog/>

## 本地开发

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

文章统一存放在 `docs/`，使用 Markdown 编写。内容围绕博士旅程、研究成长、项目实践和生活随笔。推送到 `main` 后，GitHub Actions
会自动构建并部署 GitHub Pages。

本仓库没有 fork 或复制其他个人博客的源码，只使用 VitePress 与 Teek 的公开软件包。
